# ClimaPlantio

## Descrição

O ClimaPlantio é uma plataforma desenvolvida para auxiliar pequenos e médios produtores rurais na tomada de decisão sobre o melhor momento para realizar o plantio.

A solução utiliza dados climáticos obtidos por satélites para fornecer recomendações simples e acessíveis.
