Dúvidas Frequentes

Entenda como o ClimaPlantio funciona na prática.

Como o sistema funciona?

Usamos dados de satélite da NASA e INPE para gerar recomendações de plantio.

É gratuito?

Sim, é um projeto acadêmico demonstrativo.

Precisa instalar app?

Não, tudo pode ser acessado via web ou Telegram (conceito).

Os dados são reais?

Simulados com base em lógica de dados climáticos reais.
